
### Dzienne cele

Zakładka „Postępy” zawiera cztery krótkie cele odnawiane każdego dnia: oznaczenie lekcji, wykonanie zestawu, rozegranie gry i zdobycie 20 XP. Po wykonaniu całego zestawu aplikacja przyznaje jednorazowy bonus **+15 XP**. Stan celu jest zapisywany lokalnie razem z datą, więc zmiana dnia automatycznie rozpoczyna nową listę.
