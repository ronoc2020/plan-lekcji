# Plan lekcji — pełny starter

## Uruchomienie
```bash
npm install
npm start
```
Następnie otwórz http://localhost:3000.

## Co zawiera
- frontend w HTML/CSS/JavaScript z responsywnym interfejsem,
- backend Express z API zadań i postępu,
- baza SQLite tworzona automatycznie przy pierwszym uruchomieniu,
- zadania jednokrotne dzięki tabeli `completions`,
- poziomy trudności, punkty XP i poziomy ucznia,
- filtry zadań, reset postępu i animacje,
- miejsce na dalszą rozbudowę mini-gier.

Mini-gra jest przygotowana jako moduł „Wkrótce”; kolejnym krokiem można dodać quiz, memory albo tryb wyścigu na czas.
