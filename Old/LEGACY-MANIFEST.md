# Legacy manifest

Pliki przeznaczone do przeniesienia do tego katalogu po wykonaniu bezpiecznego rename w Git:

- `app.js` — legacy JavaScript;
- `styles.css` — legacy stylesheet.

Obecny `index.html` korzysta z inline CSS i inline JavaScript, dlatego przeniesienie tych plików nie powinno odbywać się przez kopiowanie skróconej treści. Muszą zostać przeniesione 1:1, a następnie należy sprawdzić GitHub Pages.
