# Pliki legacy

Ten katalog jest przeznaczony na pliki starej implementacji, które nie są już źródłem uruchamiania aplikacji.

## Aktualny stan

- `index.html` pozostaje aktywnym punktem wejścia i zawiera aktualny plan lekcji oraz działające UI.
- `src/` zawiera moduły nowej architektury.
- Rootowe `app.js` i `styles.css` są zachowane jako legacy do czasu przeniesienia ich pełnej zawartości 1:1.

Nie wolno usuwać ani skracać danych planu lekcji podczas porządkowania plików.
